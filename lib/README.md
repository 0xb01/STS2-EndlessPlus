# Dependency Assemblies (`lib/`)

This directory contains the required assemblies for turnkey compilation and GitHub Actions CI runner builds:
- `GodotSharp.dll` (Godot 4.x C# Runtime)
- `sts2.dll` (Slay the Spire 2 Core Assembly)
- `0Harmony.dll` (Harmony Bytecode Patching Library)
- `BaseLib.dll` (BaseLib Mod Configuration UI Library)
